# IP Obfuscator

Bu araç, verilen bir **IPv4 adresini** sayısal (decimal) formda **obfuscate** eder.  
Amaç, IP adreslerini daha az okunur hale getirerek basit gizleme (obfuscation) sağlamaktır.

## Ne yapar?
- Komut satırından girilen IPv4 adresini alır
- IP’yi hexadecimal bileşenlere ayırır
- Tek bir **decimal sayı** olarak çıktı verir

## Kullanım
```bash
ip_obfuscator.exe 192.168.1.1
Obfuscated : 3232235777```
